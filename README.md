# Slot Machine

A classic three-reel slot machine built with React, TypeScript, and [Wired Elements](https://github.com/rough-stuff/wired-elements).

## Features

- Three reels with symbols 1–9
- Staggered reel stops (left to right) for tension
- Designed outcomes with a 25% win rate
- Win/loss score tracking
- Hand-drawn sketch UI

## Run locally

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm test` — run unit tests
